# 02 · 定时 / 间隔拍摄

> Status: claimed（计划器+控制器+UI 完成，单测绿；真机间隔待验收）
> 上游：`.scratch/m6-pro-remote/spec.md`、01

## 范围

- 定时：延时 N 秒后拍 1 张
- 间隔：每 N 秒拍 1 张，共 M 张；可随时停止
- 执行中显示倒计时/已拍张数；结束给汇总
- 提示音（可选，默认开）与屏幕常亮（后续小项）
- 状态机单测：开始/倒计时/拍摄/停止/完成/相机忙重试

## 验收

- [x] 单测：间隔计划器（起止时间、张数、取消）
- [ ] 真机：3 张 × 5 秒间隔，相机实际出 3 张
- [ ] 真机：中途停止不再触发后续快门
- [x] 相机忙时自动重试一次，仍忙则终止并提示
- [x] 屏幕常亮（取景/间隔/包围运行时）
- [ ] 提示音（可选，默认开）
