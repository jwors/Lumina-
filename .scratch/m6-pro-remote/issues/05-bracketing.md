# 05 · 曝光包围 / 对焦包围

> Status: claimed（计划器+执行器+UI 预设完成；Z30 真机待验收）
> 上游：`.scratch/m6-pro-remote/spec.md`、01/03

## 范围

- 曝光包围：起止 EV、张数、步长；逐张写曝光补偿（0x5010）→ 拍 → 结束回 EV 0
- 对焦包围：起点、步长、张数、方向；`MfDrive(0x9204, [方向, 步长])` 步进 + 稳定等待 + 反向回位
- 计划器与执行器分离，可单测；执行中可停止；与实时取景/间隔互斥
- 结果按相机原文件名入库（如开启拍后回传）

## 验收

- [x] 单测：包围计划器（EV/步长/张数、越界夹取、回位步数）
- [ ] 真机：3 张 -2/-1/0 EV 包围，相机出 3 张不同曝光
- [ ] 真机：对焦包围 3 张，焦点从前到后移动；结束回位

## 证据

- `ExposureBracketPlan` / `FocusBracketPlan` + `BracketPlanTest` 5 例。
- 曝光补偿走 `SetDevicePropValue(0x1016)` + `0x5010 INT16`；对焦步进走 `MfDrive(0x9204, [方向, 步长])`（gphoto2 ptp.h 口径），
  `0xA00C/0xA00E` 视为步进到头/不足并收口。
- 相机页「包围拍摄」：曝光 -2/-1/0 EV、对焦 3 张 × 2 步；运行中可停止，结束自动回位。
- 单测 195 全绿；APK 已装。
- **真机待验收**：MfDrive 的 (方向, 步长) 参数顺序与方向语义、0x5010 是否支持写入，需 Z30 开 Wi-Fi 后按日志收口。
