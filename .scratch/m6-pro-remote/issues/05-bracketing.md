# 05 · 曝光包围 / 对焦包围

> Status: ready-for-agent
> 上游：`.scratch/m6-pro-remote/spec.md`、01/03

## 范围

- 曝光包围：起止 EV、张数、步长；逐张写曝光补偿→拍→回读
- 对焦包围：起点、步长、张数、是否回位；`AfDrive` 步进 + 稳定等待
- 计划器与执行器分离，可单测；执行中可取消
- 结果按组命名/入库

## 验收

- [ ] 单测：包围计划器（EV/步长/张数、越界夹取）
- [ ] 真机：3 张 ±1EV 包围，相机出 3 张不同曝光
- [ ] 真机：对焦包围 3 张，焦点从前到后移动
