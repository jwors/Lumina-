# Master / Work 非破坏处理模型

照片处理管线决定为非破坏性：相机导出的原片（NEF/RAW + JPEG）作为 Master 永不修改，所有滤镜（.cube LUT）、LLM 标注与生成式处理只产出 Work 成品文件；换滤镜/换配方随时可重新生成。决定的动因：徒步场景单片宝贵（不可重拍），任何"烧入式"编辑一旦误操作都无法回退；且生成式风格卡（zine-poster 类）迭代极快，Work 必须廉价可弃、Master 必须恒定。

## Consequences

- 存储引擎需要区分 Master（只读、计数备份状态）与 Work（可清理、按配方可再生成）两类实体。
- 云端 API 费用发生在 Work 生成时，重跑同一配方即重新计费，需在 UI 上提示。

## 修订（2026-11-08）：JPEG Master 显式覆盖例外

M2 智能链路评审（会话拍板，用户直接确认）：在"保存方式"收尾节点引入 **覆盖 Master** 选项，与"另存 Work"并列二选一。约束与理由：

- **仅限 JPEG Master**。NEF/RAW 无对应 Work 覆盖语义，强行以 JPEG 替换 RAW 底片被排除；NEF 强制走另存。
- **必须显式选择**。默认/推荐项恒为"另存 Work（无损）"；覆盖项带"谨慎/不可恢复"标记，CTA 按钮文案动态显示 `确认覆盖 N 张` 两重确认语义。
- **成片先入 Work 层，覆盖只是"把 `_w.jpg` 内容写回 Master 路径"**这一物理动作；盘点行 `sizeBytes` 同步修正（reconcile 语义，ADR-0004 允许）。
- 本修订不推翻非破坏性原则的其余内容：默认路径全部走 Work；覆盖是少数、显式、有警示的操作。Work 依旧廉价可弃。
