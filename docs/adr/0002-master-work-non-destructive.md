# Master / Work 非破坏处理模型

照片处理管线决定为非破坏性：相机导出的原片（NEF/RAW + JPEG）作为 Master 永不修改，所有滤镜（.cube LUT）、LLM 标注与生成式处理只产出 Work 成品文件；换滤镜/换配方随时可重新生成。决定的动因：徒步场景单片宝贵（不可重拍），任何"烧入式"编辑一旦误操作都无法回退；且生成式风格卡（zine-poster 类）迭代极快，Work 必须廉价可弃、Master 必须恒定。

## Consequences

- 存储引擎需要区分 Master（只读、计数备份状态）与 Work（可清理、按配方可再生成）两类实体。
- 云端 API 费用发生在 Work 生成时，重跑同一配方即重新计费，需在 UI 上提示。
